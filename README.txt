UNDANGAN DIGITAL SYAHRIN & ROFI
================================

Isi folder:
- index.html       halaman undangan
- assets/          foto dan musik yang Anda unggah

CARA MELIHAT:
1. Ekstrak ZIP.
2. Buka folder undangan_syahrin_rofi.
3. Klik dua kali index.html (Chrome/Edge disarankan).

3. Pastikan Anda memiliki hak/izin untuk menggunakan file musik yang diunggah dan membagikannya dalam undangan online.

PUBLIKASI GRATIS:
Anda dapat memakai GitHub Pages (gratis untuk repositori publik):
1. Buat akun GitHub gratis di github.com.
2. Buat repository baru, misalnya undangan-syahrin-rofi.
3. Unggah index.html dan seluruh folder assets (jangan hanya index.html).
4. Buka Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Setelah proses selesai, GitHub Pages menampilkan alamat website publik yang dapat dibagikan.

Tidak perlu paket hosting berbayar untuk langkah di atas. Saya belum menerbitkan situs ke internet; publikasi memerlukan akun/aksi pemilik akun GitHub.
